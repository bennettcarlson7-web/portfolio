# HTML/CSS Portfolio (project1)

Pure **HTML + CSS** version of the Joseph Zhang portfolio — same layout and design as the Next.js site. No React, no build step, no Node.js required to view.

## Files

| File | Purpose |
|------|---------|
| `index.html` | Full single-page site |
| `styles.css` | All styles, animations, and backgrounds |
| `icon.svg` | Favicon |

## View locally

**Open in browser:** double-click `index.html`.

**Local server (recommended for images):**

```bash
npx serve .
```

Or from the repo root:

```bash
npm run html:dev
```

## Deploy

Upload this entire folder to GitHub Pages, Netlify, S3, or any static host.
